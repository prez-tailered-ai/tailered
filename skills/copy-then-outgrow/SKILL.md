# Copy, then outgrow

Build the company's own version of a rival feature that works, then measure whether it beats the original. Instagram took Snapchat's Stories format in 2016, credited it openly, and was reported to pass Snapchat's daily users within a year. The guard: Facebook's earlier Snapchat-style apps, Poke (2012) and Slingshot (2014), were shut down. A copy that never beats the original is a cost, so the scorecard and the stop date come before the build.

## When to Activate

- A rival has a feature members like or ask about.
- The owner says "copy what works", "they have it, why don't we" or "beat their version".
- A copied feature is live and has no comparison with the original.

Do not use for:
- a new feature from a member's ask, with no rival version: tailered-ai:press-release-first;
- a public accuracy contest: tailered-ai:prove-it-in-public;
- bringing in the rival's tool itself: tailered-ai:license-not-rebuild.

## Inputs and outputs

Where to work: create a task folder, `artifacts/<skill name>-<YYYYMMDD>/` in the current project (this session's scratchpad if the project is read-only), and write the output there. Tables go in your reply.

Inputs: the rival, the feature, what members say about it, and the company's planned version.

Missing inputs never leave a blank. Put in a concrete proposal from what you know, mark it `proposal`, finish every step, and end with the one or two inputs that would change the result.

Output: `scorecard.md`: the job the feature does, the head-to-head number frozen before launch, the edge the company adds, the check date, and the verdict.

## Steps

### 1. Name the job, not the look

Say what the feature does for a member in one sentence, such as see every market price for one game in one row. Copy that job. Do not copy the rival's name, text, images, code or data; build the company's own version, estimates only, never advice.

Completion: one sentence naming the job, and a note that no rival content is reused.

### 2. Freeze the scorecard

Before anything ships, pick one number both versions can be judged on: use per member, time to the answer, or accuracy against the closing line. Write the rival's number, or a `proposal` estimate, and the number the company must reach by a check date.

Completion: the number, both values, the check date, and the file saved before launch.

### 3. Add one edge

Name what the company adds that the original lacks, such as the model's projection beside Partner A and Partner B prices. A copy with no edge can only tie.

Completion: one named edge.

### 4. Judge at the date

Read the number at the check date. Give keep (beats the original), change (close; one named change) or stop (behind; remove it). Name the owner who reads it. Building and removing ship through tailered-ai:workflow and the release coordinator on the owner's word.

Completion: the verdict with the two numbers that decided it, the owner, and the release route named.

## Anti-Patterns

- Copying the look and missing the job.
- Setting the target after launch.
- Reusing a rival's text, images or data.
- Keeping a copy that never beat the original.
