# Flywheel map

Draw the loop that compounds, then push one input you control. Bezos sketched Amazon's flywheel in 2001: lower prices bring customers, customers bring sellers and selection, which bring more customers, and scale lowers costs and prices again (Collins, 2019). The guard: Amazon ran on thin or no profit for years, and a loop on a whiteboard is a guess until each link has a number.

## When to Activate

- Deciding where effort or money goes next.
- The owner asks for a flywheel, a growth loop or "where to push".
- A plan claims a change will "drive growth".

Do not use for:
- setting a price: tailered-ai:price-forces-cost;
- finding where growth hits a limit: tailered-ai:growth-cap-check.

## Inputs and outputs

Where to work: create a task folder, `artifacts/<skill name>-<YYYYMMDD>/` in the current project (this session's scratchpad if the project is read-only), and write the output there. Tables go in your reply.

Inputs: the current numbers that exist: members, renewal, accuracy against the close, main product visits, costs.

Missing inputs never leave a blank. Put in a concrete proposal from what you know, mark it `proposal`, finish every step, and end with the one or two inputs that would change the result.

Output: `flywheel.md`: the loop, a link table with evidence, the weakest link and one input to push.

## Steps

### 1. Draw the loop

Four to six links, each "more A brings more B", closing back to the start. A starting draft for the company: projections that beat the close bring trust, trust brings members, members bring revenue and data, and those pay for a better model.

Completion: a closed loop of four to six links.

### 2. Put a number on each link

For each link, give the measured evidence and its source, or write `guess`. A correlation is not a link until something shows the first drives the second.

Completion: every link has a number with a source, or the word guess.

### 3. Find the weakest link

The guess, or the smallest measured effect.

Completion: one link named.

### 4. Pick one input to push

Choose something the team moves directly this month, such as accuracy against the close, main product freshness or time to publish, never an output like revenue or members. Set the number that shows it moved, and the date.

Completion: one input, its target and its date.

## Anti-Patterns

- A loop with no numbers.
- Pushing an output instead of an input.
- Cutting price by default to spin the loop; it spends margin.
- Calling every link proven.
